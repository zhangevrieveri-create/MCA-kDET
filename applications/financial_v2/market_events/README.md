# 市场事件下的模块分布与风险后果：首轮探索

研究问题由用户确定为：市场阶段切换时，哪些行业/风险模块发生分布变化，变化是否伴随更大的下行风险，而不是简单检验行业彼此不同。

本轮为三个案例各五模块，数据量小；没有新增大规模模拟。2015的三阶段由用户选择。窗口、模块、分割和主多重调整均在本轮新p值前写入protocol.json；因研究问题在旧分析之后调整，不冒称研究开始前预注册。

## 案例与观测

- A股2015：2015-01-05至03-31上涨、04-01至06-12高位见顶、06-15至09-30回撤。6月12日为上证综指当年最高点日期，是事后历史锚，不是实时交易信号。
- A股9·24：2024-03-28至06-27较早前期、06-28至09-23临近政策前、09-24至12-23政策发布后，各60交易日。9月24日用作政策发布日期，不预设永久牛熊转换或因果效果。
- 美股2020：2019-09-30至12-23、2019-12-24至2020-03-20、2020-03-23至06-16，各60交易日。3月23日为美联储政策公告锚，背景为疫情冲击，不将所有变化归因于单一政策。

各模块一条日向量，固定资产坐标跨阶段保持，不排序、不跨股平均。主检验使用共同事件前GARCH过滤后的向量；原收益描述下行后果。每阶段原日历前40%拟合分类器，中间五个交易日缓冲，余下留出；缺失掩码之后应用，不压缩日历。

中国为银行5股、非银行金融5股、房地产3股、建筑3股、食品饮料2股，按2014年历史权重在原先独立选定的30股缓存中确定。两次事件均保持同一历史篮子，不是2024全行业总体，不能外推所有行业成分。美国为金融体系4、科技4、防御消费5、工业周期5、能源材料5个行业组合坐标；来源是Kenneth French每日市值加权组合，不是任意幸存个股名单，也不与中国模块逐项排名。

## 数据来源

- 中国：之前用户授权米筐下载的2010–2025行情缓存、历史权重和分类，本轮未重新索取或保存密钥。
- 美国：官方公开49行业每日收益压缩包，约4.18 MB。保留原ZIP、SHA256及下载时间，解析第一个每日市值加权表；缺失哨兵先转缺失，百分比简单收益转为百分比对数收益。最新版本可能修订历史，不冒称实时数据版本回测。
- 数据源及事件原始来源URL见source_audit.json；原ZIP在raw，分析只使用相关历史时段。

## 执行与核验

1. prepare_market_events.py：读取原缓存、下载公开美国数据、固定模块与时间格，输出feasibility.csv、phase_calendar.csv及每模块输入。全部45阶段拟合/测试完整样本均至少12；实际测试21–40条/阶段。
2. run_event_analysis.R：先银行一模块B39通过，再15模块B4999、30核（最多15任务）。每坐标GARCH仅在事件前基线拟合一次并共用于三阶段；冻结学习器、统计量和置换引擎不改。
3. report_market_events.py：纯Python解析15个RDS，核对源MD5、原p、原日历分割、滤波均值/方差递推及缺失；生成完整结果和风险指标。
4. verify_real_analysis.py --directory market_events --expected-rows 60 --expected-jobs 15 --expected-primary-cells 15：独立复算60个p和15配置全部5000列标签的四方法统计量，最大误差1.8e-13、p一致。滤波递推最大误差2.4e-15。
5. plot_market_events.py：输出六面板图，左列为过滤后分布筛查，右列为原收益阈值越界比例。字体、对齐和最终PDF碰撞核对通过；矩阵内文字覆盖为预期标签。

## 主结果与边界

2026-10-28置换精度复核：全部15项MCA统一从B4999增至B49999，保存原4999次后追加45000次，不重训、不换窗口、不改Holm家族。美股防御消费p=0.00248、Holm=0.0372，国内两例仍无调整后拒绝。原四方法对照和图保持B4999，新旧MCA对照在同一Excel第一页下半部。详情见mc_precision/README.md；增加置换次数仅减小蒙特卡洛误差，不增加实际样本或解决依赖有效性。

MCA跨全部15模块Holm后，国内两个案例都未跨名义0.05；美股2020防御消费原始p0.0024、Holm0.0360，三个对照方法同方向。其他模块也完整报告，不宣称本例中MCA胜过所有对照方法。

原收益风险变化与过滤后的分布变化是两层问题。例如2015建筑模块的“至少半数成分跌破各自基线5%左尾阈值”的日比例为14.0%/27.5%/41.4%，但过滤后MCA不拒绝；不能以不拒绝认定风险稳定或GARCH模型充分。

阈值越界比例不是纯尾部依赖系数；两维食品饮料中至少半数包含单个成分。只在同一模块跨阶段比较，不按绝对比例跨模块排名。另给等权日简单收益组合的最差10%日平均损失（先将各股对数收益转简单收益，再等权），仅用于描述后果，不替代完整向量检验。尾部只有5–8日，未加置信区间，不能充当独立筛选后验证或韧性排名。

新事件设计尚未完成针对性的依赖校准，既有失败记录保留，全部数值为探索性。前后比较不是因果效应，显著不等于风险更大，未拒绝不等于抗跌。2010-02-12广发证券基线有一条155.69%的日对数收益，按来源原样保留并记录于data_quality_flags.csv，后续应核对历史复牌/公司行动，不根据p值自动删去或缩尾。
