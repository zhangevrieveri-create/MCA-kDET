# GARCH调整后的创新分布检验

2026-10-27，用户明确选择“增加GARCH调整后的创新分布检验，原始收益保留描述分析”。本方案优先于原收益方案中的正式检验部分。股票名单、选择规则、2015–2017拟合期、20交易日缓冲、2018–2024测试期均沿用。

## 检验对象

每只股票用常数均值GARCH(1,1)：`r_jt=mu_j+sqrt(h_jt)*epsilon_jt`。比较去掉各自条件均值和波动后的五交易日创新向量分布；不再声称检验的是原始收益同分布，不据此判断股票的原始风险、收益、走势或完整随机过程相同。

行业内三项仍为每股一个总体、各k=5；行业间为每行业五股等权混合、k=3。全部四项完整报告、Holm调整。不用结果筛选股票或行业。原始收益的固定顺序距离图继续保留，不能与创新距离混用。

## 滤波规则（在计算新p值前固定）

- 各股均值与高斯QML的omega/alpha/beta仅用2015–2017本股有效日收益估计；均值为拟合段样本均值。学习器的训练期相同。
- QML的三组起点持续性为0.85/0.95/0.985，Nelder–Mead最多4000步、相对容差1e-10；在收敛起点中取目标最小者。强制omega>0、alpha/beta>=0、持续性<0.9995，边界与失败起点全部记录。不用测试段拟合优度或p值挑选起点/模型。
- 初始方差为拟合段中心化二阶矩；完整交易日历向前递推，`h_t=omega+alpha*(r_{t-1}-mu)^2+beta*h_{t-1}`。上一日收益缺失时，以其预测条件二阶矩h代替平方残差，即期望递推，不填造收益。
- 测试期参数固定；当日条件方差只依赖此前观测。缓冲期历史用于向前更新方差。模型需要的过去信息可以使用，不查看未来。
- d5/d20向量沿用原始收益的起止日、非重叠划分、共同缺失标记；滤波不会把缺失收益变为有效观测。输出方差始终为正，创新在原缺失处仍缺失。
- 不把滤波后ACF较小当成独立性的证明；仍保留同期全股票联合记录和同步时间重抽样。

## 必须区分的两种误差

真实创新不可观测，估计滤波器得到的是标准化残差。各股分别估计均值和波动参数，会引入组别不同的估计误差。因此不能因原E8通过，就直接宣布本应用有效：E8在同一坐标上比较不同外部状态，同一坐标的过滤器是共享的；本应用是不同股票各自拟合过滤器。

校准模拟必须重新估计过滤器，并同时保存“真参数/真创新”的基准。真创新下控制水平而估计残差下失控，就需要处理第一阶段估计误差；不能仅对固定残差重抽样就称已经完成校准。

训练段参数误差也会影响残差经验分布，相关文献仅供推导参考，不是本算法已有证明：[Chan等，Statistica Sinica (2009)](https://www3.stat.sinica.edu.tw/sstest/j19n1/j19n12/j19n12.html)。递归生成收益并重新估计参数的残差块bootstrap是可研究的路线，但现有结果讨论的是参数/波动率推断，不能直接套到最大AUC：[Beutner等 (2026)](https://link.springer.com/article/10.1007/s10182-026-00560-x)。

## 执行顺序

1. 原收益失败记录完整保留；不继续采用其校准推断真实收益。
2. 机械检查：原生递推与逐步R计算一致；修改未来测试数据不改变训练参数或此前方差；缺失标记不变。然后估计15股滤波器、独立复核递推、记录ACF和同期相关。
3. 创新校准：先少量试跑，真创新与估计创新平行；原假设包括相同和不同GARCH参数但创新分布相同、持续性0.95/0.99、厚尾。共同因子载荷不同，保留非交换同期相关及真实缺失日历。第一阶段每次重新估计。
4. 同步块候选以d5的8段为主，并检查1/4段；B=999作校准试跑。先每场景100次；有可行固定方案后，用未使用的模拟种子各1000次确认。不能按真实p值选校准。
5. 校准成立后再运行真实四项检验和d20检查，正式重抽样B=4999。若估计误差导致失控，继续校准开发或与作者讨论模型假设，不制造正式p值。

论文和冻结R模型、校准常数、置换引擎不改。当前创新实证的结论待计算与验证。
