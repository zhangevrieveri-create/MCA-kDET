## 四类检验及各自的观测单位

### A. 同一资产面板在不同市场状态下是否同分布

每周一条向量，坐标为同一固定资产面板的各股收益。总体标签分别为牛/熊/震荡；另用国内波指的高/中/低波动作平行设计。比较向量的整体分布，均值、波动、相关和更高阶结构的变化都可能导致拒绝，不能预先解释成只存在依赖结构变化。

### B. 各行业内部，在不同市场状态下是否同分布

对预先选择的每个行业，固定其股票面板，分别重复A。候选行业银行、医药、机械、食品饮料有不同经济暴露，当前历史名单数量允许进一步检查。行业选择、股票数与质量规则在看新p值前确定；所有行业的结果均保留，不能只展示显著行业。

### C. 不同行业中个股收益数据的分布是否相同

行业是总体。先定义行业总体为所选成分股的**等权混合分布**，再比较不同行业的混合分布。每条数据来自某只股票的一段收益，采用所有行业共同的特征坐标，例如单周收益（1维）或互不重叠的5交易日收益向量（5维）；行业之间保持共同日期及预先固定、平衡的选股规则。

这回答的是行业内个股收益分布的整体差异。行业指数/组合收益可另外作描述或补充，但它检验的是聚合收益分布，不能替代上述个股混合分布问题；任意各取d只股票并把它们随意排成d维坐标，也不能不解释坐标对应就称为行业可比。

### D. 同一个板块内，不同股票是否同分布

每只股票是一个总体，k为股票数，检验 `H0: F_1=...=F_k`。各总体使用共同时间段、共同特征定义的收益观测。可先比较单周收益，再以互不重叠的5/20交易日收益向量作多维版本；不同长度向量对应不同对象，须分别说明，不能把重叠窗口当成独立重复。

同分布比较不要求同一天的涨跌或收益数值相同，也不能据同分布推断完整随机过程相同。若只比较1维收益，结论只覆盖该边际分布；若比较长度d的收益块，结论只覆盖所定义的d维块分布。

## 预处理与校准原则

- 不比较价格的绝对水平；先统一复权收益定义与日期。主要对象为原始复权收益的分布，公共尺度如有需要只能由共同训练数据估计。
- 不先逐股减去各自均值再各除各自标准差，却仍声称检验原始收益同分布；这会主动移除关注的均值和波动差异。GARCH或边际波动调整只能作为明确改变目标分布的另一分析，并单独解释。
- B/C/D可能共享同期观测，股票还具有市场共同因子；不能把股票或股票×日期的每一行当成相互独立，也不能认为简单把日期分块后普通标签置换就自动有效。
- C/D的数据准备要保留同一个时间块内全部股票及行业的同步记录。候选推断是在保持同期联合结构的时间块重抽样中，对固定分类器的AUC分量做适当的原假设中心化，再校准最大统计量；**整块重抽样自身不自动形成原假设分布**，具体一致性条件、中心化和有限样本实现须与作者共同核对，暂不宣称已有证明。
- 只需调用冻结学习器和统计量的应用包装层；不改 `R/tests.R` 的核心函数。需要依赖样本理论扩展时，与作者合作，不把iid定理直接套过来。
- 先固定问题、样本与校准，再计算新检验；随后完整报告主分析、所有行业与不利结果。旧美国VIX结果不充当新实验结果。
