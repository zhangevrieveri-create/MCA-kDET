# 交接说明：模拟框架（怎么加模型、学习器、实验，怎么验证、运行和出表）

2026-10-22 编写。交给新窗口做模拟任务时使用：读本文件和 `工作总览.md` 就够了，不必读代码全文，按这里给出的位置去改。项目规则以根目录的 `CLAUDE.md` 为准。

## 0 必须遵守的规则

1. **每次运行之前**（测试、试跑、正式运行都算），先把参数列给用户、等用户确认。用户明确授权"不用问"的除外。
2. **两个版本：** 修订设计中的每个实验都要同时有**精确版（full）和快速版（quick）**的次数，只差重复次数。现在出结果用快速版。
3. **冻结、不能改的文件：** `R/models.R`、`R/calib_params.R`、`R/calib_params_v2.R`，以及 `R/tests.R` 里的置换引擎（`perm_labels`、`ovr_T`、`pval_perm`、`pval_comb`）。确实需要改时，先征得用户同意，并优先用"新文件 + 钩子"的方式（见第 3 节）。
4. 不删除已有结果；新的运行写到新的目录或新的实验名下。
5. `run.R` 不会自动安装任何包。需要新包时，让用户先单独装好。
6. 汇报用中文表格，如实报告不利结果。

## 1 代码地图（`sim/`）

| 文件 | 主要内容 |
|---|---|
| `R/models.R`（冻结） | `gen_population(model, beta, n, d, g, k, par)`，用 `switch(model, ...)` 生成第 g 个总体的 n×d 矩阵；`gen_data(model, beta, n, d, par)` 生成 k 个总体。约定：第 k 个总体偏离，β = 0 时所有总体同分布。已有模型：A、B、C（即 C′）、C2、D、E |
| `R/learners.R` | 网络 `nn_fit` / `nn_score`；`l1_fit_score`（glmnet，C 网格 `L1_C_GRID`，按总体分层的 3 折 CV，`L1_MAXIT = 1e4`，不收敛次数通过 `glmnet_counted` 计数）；`standardize_fit`、`apply_std`、`auc_vec` |
| `R/learners_lib.R` | 学习器的统一接口 `learner_<name>(X, y, w, grp, Xnew, ...)`，返回 `list(score, info)`；已有 `l1`、`quad`（`QUAD_MAX_PAIRS = 1000`）、`knn`（`KNN_K_GRID` 加上 ⌈√N_fit⌉）、`rf`（ranger）、`nn`；`LEARNERS` 是可用学习器的名单；`parse_lib`、`parse_libsets` 解析库和库组合 |
| `R/tests.R` | `split_data`（每个总体内随机拆分）；`ovr_weights`；`fit_scores(sp, groups, nn_cfg, lib)` 拟合 ovr、shared、pair 三组；`classifier_tests(sc, B, libsets)` 用同一组置换算出所有分类器类 p 值；`competitor_tests(data, B, groups)` 计算 dist 组（DISCO、MMD、MST）和 schott 组 |
| `R/sim.R` | `one_rep(cell, r)`：种子 = seed0 + r → 生成数据 → 拆分 → 拟合 → 检验 → 对比方法，输出一行结果；`safe_rep` 出错时用同一种子重试；`run_cell` 按块写盘，并调用进度回调；`make_cluster` 在每个 worker 里加载代码文件 |
| `R/experiments.R` | `PAR`（E0 冻结的常数）；`cell_row(...)` 生成一行格子定义，种子方案用 `seed_scheme = "v1"/"v2"`；`LIB_MAIN = "l1,quad,knn,rf"`；修订设计的工具：`V2_EXPS`、`REPS_V2` 加 `nrep(key)`（两个版本的次数表）、`PAR2`（第二次校准）、`v2(...)`（修订设计的一个格，默认库、种子方案 v2）、`SC_V2 = 10`、`D_C_V2 = 20`、`GRID_FRAC`；`make_grid(exp)` 里定义每个实验的网格 |
| `R/summarize.R` | `P_COLS`（固定的 p 值列）；`read_exp(exp, outdir)`；`summarize_exp`：拒绝率加诊断列的均值，按正则自动收集 `mca_*`、`pair_*`、`auc_*_dev`、`<学习器>_<K/log10C/nnz/nonconv/epochs>` |
| `run.R` | 入口：`--exp`、`--profile=quick|full`（E1–E7 必须给）、`--cores`、`--reps`、`--B`、`--filter`、`--chunk`、`--out`；带进度条；加载包失败时重试 3 次 |
| 出表 | `report_v2_E1.R` 到 `report_v2_E7.R`（`--out=` 选择目录）、`analysis_theory_checks.R`、`report_libpilot.R` |
| 测试与工具 | `tests/test_compat.R`（旧库下 p 值必须逐位不变）、`tests/test_learners.R --part=1/2/3`（信号、水平、可复现）、`tests/check_seeds.R`（种子是否重叠）、`tests/rebuild_chunk.R`（从 `.debug.rds` 拼回出错的块）、`tests/diag_*.R`（glmnet 诊断）、`tests/compare_glmnet_fix.R` |

**一次重复里的列：**
- p 值：`mca`（整个库）、`mca_<学习器>`、`mca_2s`、`mca_sum`、`mca_comb`、`mca_set_<a+b>`、`pair`、`pair_<学习器>`、`shared_nn`、`shared_lib`、`macc`、`disco`、`mmd`、`mst`、`schott`、`mca_ms_med` / `mca_ms_mean`（多次拆分时才有）
- 诊断：`T_<学习器>_dev`、`auc_<学习器>_dev`（偏离总体的 T 和测试 AUC）、`<学习器>_K/log10C/nnz/nonconv/epochs`、`acc_obs`、`argmax`
- 计时：`t_*`

## 2 运行与故障处理

- **命令：** 在 `sim/` 下运行 `"D:/R-4.6.1/bin/Rscript.exe" run.R --exp=<实验> --profile=quick --cores=30`。长时间的运行放在终端面板里跑（Claude 用 `run_in_terminal`），用户能看到进度条。
- **等待：** 在后台循环检查 `<结果目录>/<实验>.log` 里有没有 `finished in`；如果日志超过一定时间没有更新就提醒用户（k = 10 的格每块可能要几十分钟，阈值不要小于 2 小时）。
- **R 的偶发故障：** 解压错误、启动时卡死、无输出直接退出、段错误。处理办法：重跑同一条命令即可续跑。主进程拼表失败的块会存成 `.csv.debug.rds`，用 `Rscript tests/rebuild_chunk.R <缺失的 csv 路径>` 拼回，它会做 5 项核对。卡死的进程请用户在终端里按 Ctrl-C，或在任务管理器里结束（Claude 的 taskkill 会被拦下）。
- **实测耗时**（快速版，30 核）：E2 32 分钟，E3 32 分钟，E4 5 分钟，E5 41 分钟，E6 7 分钟，E1 9.3 小时（glmnet 修复前；修复后估计约 5.5 小时），E7 4 分钟。精确版估计约 20 小时。

## 3 怎样新增内容（逐步）

### 3.1 新增一个数据模型（例如 E8 用的 GARCH 原假设）

`R/models.R` 是冻结的，**推荐用钩子**（要先征得用户同意，目前还没有实现，见任务 S0）：

1. 新建 `R/models_ext.R`：
   ```r
   gen_population_base <- gen_population
   gen_population <- function(model, beta, n, d, g, k, par) {
     switch(model,
       GARCH = { ...返回 n×d 矩阵；β = 0 时所有总体同分布... },
       gen_population_base(model, beta, n, d, g, k, par))
   }
   ```
   `gen_data` 是按名字调用 `gen_population` 的，所以在全局环境里重新定义之后就会生效。
2. 在 4 个地方的加载列表里，把 `"models_ext.R"` 加在 `"models.R"` 后面：`run.R`（第 42 行附近）、`R/sim.R` 的 `make_cluster`（第 140 行附近）、`tests/*.R` 各脚本、`tests/check_seeds.R`。
3. **模型参数：** 目前只有 `cA`、`cB`、`sC`、`cE` 四个参数，从格子的列传进 `par`（`R/sim.R` 中 `one_rep` 的 `par <- list(...)`）。新参数建议加一个通用列 `mpar = "key=value;..."`：在 `cell_row` 里加这个参数和列，在 `one_rep` 里解析后并入 `par`（仿照 `nn_config` 的写法）。默认值为空字符串，这样旧的格子行为不变。
4. **模型的要求：** 只能用 R 的随机数流；β = 0 时 k 个总体必须同分布（否则水平实验没有意义）；返回数值矩阵。
5. 如果数据不是独立同分布的（例如 GARCH），还要考虑**拆分方式**：`split_data` 是在每个总体内随机拆分，第 3.1 节说金融应用用的是"连续分块并留缓冲区"。需要另写一个拆分函数，由格子里的新列控制（`R/tests.R` 里的拆分函数不属于冻结的置换引擎，但改动要向用户说明）。

### 3.2 新增一个学习器

1. 在 `R/learners_lib.R` 里写 `learner_<name>(X, y, w, grp, Xnew, ...)`。要求：只能用 X、y、w、grp 和 R 的随机数流（第三方包的种子从随机数流里抽）；分数越大越像总体 i；`info` 里只放标量。
2. 把名字加进 `LEARNERS`；`R/summarize.R` 里诊断列的正则 `(l1|quad|knn|rf|nn)` 也要加上；`report_*.R` 里的 `LRN` 列表也要加。
3. 如果需要新包，先请用户安装，并在 `make_cluster` 里加一行 `requireNamespace`。
4. **验证：** 解析检查 → `tests/test_compat.R`（必须 COMPAT OK）→ 把它加进 `tests/test_learners.R` 的 `ALL`，跑第 1、2、3 部分 → 试点。

### 3.3 新增一个对比方法

在 `R/tests.R` 的 `competitor_tests` 里加一个组（像 `"dist"`、`"schott"` 那样），返回 p 值；把列名加进 `R/summarize.R` 的 `P_COLS`；在 E1 类的原假设格上检查它的水平。

### 3.4 新增一个实验（例如 E8）

1. 在 `R/experiments.R` 的 `make_grid` 里加 `E8 = ...`，用 `v2(...)` 生成格子（默认库、种子方案 v2）。次数用 `nrep("E8_null")` 之类的写法，并在 `REPS_V2` 里同时写上 `full` 和 `quick` 两个次数。
2. 把实验名加进 `V2_EXPS`（检查重复种子）和 `tests/check_seeds.R` 的 `newx`。`run.R` 里 `is_v2 <- exp_name %in% paste0("E", 1:7)` 是写死的，要改成包含新实验（建议改成 `exp_name %in% setdiff(V2_EXPS, "calib2")`，见任务 S0），否则结果不会写到 `results_v2_<profile>/`。
3. 跑 `tests/check_seeds.R`，必须显示 SEEDS OK。
4. 仿照 `report_v2_E4.R` 写一个 `report_v2_E8.R`。
5. 把新实验加进 `run_v2_quick.bat` 和 `run_v2_full.bat` 的循环，并更新 `运行说明_精确版与快速版.md` 里的次数表。
6. **如果需要校准**（定常数或 β 网格）：沿用 E0 的规则（最好的方法在网格最大 β 处功效 ≥ 0.95；β_fix 让 k = 3 时 MCA 功效约为 0.6–0.8），每格 50 次；结果放在新文件 `R/calib_params_v3.R` 里，经用户同意后冻结。不要改已冻结的文件。

### 3.5 任何改动后的验证顺序（每一步跑之前都先请用户确认）

解析检查 → `tests/test_compat.R`（旧库下 p 值逐位不变）→ `tests/test_learners.R` 第 1、3 部分（改了学习器还要跑第 2 部分）→ `tests/check_seeds.R` → 试跑 `--reps=3 --B=19 --out=results_trial_<实验>` → 快速版正式运行 → 出表 → 如果涉及理论，再跑 `analysis_theory_checks.R`。
