## 0 修订的原因（摘要）

1. 默认库从 {l1, nn} 换成了 **{l1, quad, knn, rf}**，MCA-kDET 的每一列都要重跑。
2. 模型 C 放在 d = 100 时，所有方法都测不出来，所以 C 移到 d = 20。
3. 新库下 D 在 β = 0.2 时已经饱和（1.00），β 网格要下移。
4. 新库不含网络，所以不再单独做"一对其余对比共享网络"的消融。

## 1 不变的部分

- α = 0.05，B = 200。
- 冻结常数：n = 300，cA = 0.6，cB = 4，cE = 0.2；模型 A、B、C′、C2、D、E 的定义不变，`R/models.R` 不改，也不加 E′【已定】。
- 对比方法和它们的实现都不变：两两最大、多类准确率、DISCO、MMD、MST、Schott。
- 每个实验只负责论证一条结论。

## 7 预计会报告的不利结果（先写下来，避免事后挑选）

- **模型 E：** DISCO/MMD 领先约 0.2–0.35（试点中 β = 1 时 0.93–0.95 对 0.61–0.72），差距只出现在很窄的信号区间。正文的解释是：样本拆分的代价、要先学到信号、求和型把无信号学习器的噪声也加进来了。
