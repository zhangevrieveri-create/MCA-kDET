# 日频五特征试验入口

用户已确认：一只股票为一个总体、一天为一条五维观测；不再用五日残差向量作为本轮输入。五维及窗口在新结果前固定于protocol.json。此为行业内部小试，原事件/五日结果不覆盖、不删除。

- `daily_feature_trial.py --fetch`：从进程环境RQDATA_LICENSE读取已授权凭证，补取OHLC、成交量/额、today换手率与停牌。不保存凭证。未设置环境且无缓存时需重新提供进程凭证；有缓存则不带--fetch即可重新整理。
- 价格统一后复权，上一交易日收盘从同一复权序列取，不混用交易所不复权prev_close。日内高低相等且有成交时，收盘区间位置固定0.5。使用停牌/成交与前一交易日状态共同掩码，不插值、不压缩原日历；完整及缺失记录分开保留。
- `run_daily_feature_trial.R --smoke=true`烟测后，`--cores=30`执行六配置（3行业×五维/价格四维），实际最多六任务。需要本机PSOCK通信权限；初次受限启动失败日志保留，已核对进程后同种子恢复成功。不要在正常运行时重复启动。冻结学习器和置换引擎未改。
- `report_daily_feature_trial.py`独立核对24个置换参考值、6000标签列四方法统计量、输入/拟合尺度及AUC，最大误差3.7e-12。价格四维两格MST在SciPy与R之间存在并列边选择差异，按冻结R的Prim并列规则跨语言复算后全列一致；不隐藏或随意换MST结果。
- `plot_daily_feature_trial.py`展示全部三行业×五特征的有效测试日ECDF，各股n明确列出。PDF/SVG/600dpi PNG，对齐、最小字号7.7pt及碰撞0FAIL/0WARN。当前为宽幅诊断图，尚非按期刊栏宽完成的正文插图。
- 原单份Excel新增“日频特征试验”“日频样本”，24个参考值/全部四学习器AUC、15股样本数及6958实际日行均保留，旧11页不删。文件保存后独立XML逐值核对通过。

最重要的边界：普通标签置换仅作独立样本参考，不能宣称真实数据p值有效。实测换手率一阶相关中位约0.672，振幅约0.500；同日跨股票相关也较强。B999下的0.001是数值分辨率下限，不是p=0，也不是依赖校准已通过。完整发现与不利结果见日频五特征试验说明.md；未改论文。
