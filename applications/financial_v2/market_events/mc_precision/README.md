# 全部15项MCA的置换精度与拆分诊断

本轮响应用户希望提高检出能力的请求。先固定plan.json，再统一将全部15项MCA由4999次置换补至49999次；保留旧结果，追加每项45000次。数据、股票、时期、共同GARCH过滤器、分类器、测试分数、统计量和15项Holm家族均不变。不根据新p停止或选择配置。此为事后精度复核，不冒称独立确认或新增功效。

结果：美股2020防御消费原p为0.0024，加密后0.00248；全15项Holm由0.0360变为0.0372。2015地产0.03130/Holm0.43820，2024银行0.07912/Holm0.87032、建筑0.08578/Holm0.87032；国内两个案例均无调整后拒绝。全部15项见results.csv。其他方法仍为B4999，原配对四方法图未改。

区间列仅为固定数据、固定训练分数下置换尾概率的逐格Clopper–Pearson 95%蒙特卡洛区间；不是经济效应区间、同时区间或水平有效性的证明。美股防御消费此区间为[0.002045, 0.002934]。其数据依赖、GARCH参数估计和事后研究选择问题仍在，不能因数值精度高而称为确证发现。

split_diagnostics.csv给出45个阶段的训练/测试起止和样本数。各阶段只有21–40条测试日向量。美国第二阶段分类器训练2019-12-24至2020-01-29，测试2020-02-06至2020-03-20；训练与测试可能覆盖不同市场状态。相应残差均值、协方差距离只是描述量，不能独立证明功效损失。增加股票数增加的是维数，不增加日期观测。

下一步设计应在看新结果前固定、验证：让训练样本能覆盖所比较的各阶段，同时对时间依赖与信息泄漏作有效控制；先用与现有小样本、过滤估计和阶段内变化相匹配的模拟评估误报/功效，再到独立历史时期验证。不能把交叉拟合得分直接合并后套用冻结置换检验，也不凭最小p挑拆分、缩小Holm家族或撤掉过滤。若共同GARCH已消除原收益的尺度变化，创新分布检验针对的经济问题也更窄；原收益风险后果继续单列。
