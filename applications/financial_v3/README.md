# 第 5 章金融实证 v3：风险状态下的"传染还是相互依存"

方案见上一级目录的 `第5章金融实证方案_1028.md`。规则冻结在 `protocol.json` 中，于计算任何检验之前固定。

## 怎么运行

1. 从 Kenneth French 数据库下载以下两个文件，放到本目录的 `raw\` 下，不要解压：
   - `30_Industry_Portfolios_Daily_CSV.zip`（30 Industry Portfolios [Daily]）
   - `10_Industry_Portfolios_Daily_CSV.zip`（10 Industry Portfolios [Daily]）

   49 行业的文件和 VIX 已经有了，程序会自动去 `../financial_v2/market_events/raw` 和 `../financial/raw` 找。
2. 双击 `run_v3_all.bat`，或在本目录的终端里运行它。它会依次执行：
   1. 数据准备：`prepare_v3.py`
   2. 生成任务：`make_jobs_v3.py`，包括生成 200 个 bootstrap 原假设数据集
   3. 小样本试跑（2 个任务，B = 19）
   4. 校准检查：800 个任务，B = 199
   5. 主分析：11 个任务，B = 4999
   6. 汇总：`report_v3.py`，输出 `results\报告_v3.md`

   中途中断后重新运行即可续跑，已完成的任务会跳过。32 核机器上预计不到 1 小时。
3. 把 `results\` 文件夹（或者至少其中的 `报告_v3.md` 和 `summary_*.csv`）发给 Claude。

## 文件

| 文件 | 作用 |
|---|---|
| `protocol.json` | 冻结的问题、数据、状态、预处理、拆分、主检验、Holm 校正、校准检查和报告口径 |
| `prepare_v3.py` | 构造周收益、滞后 VIX 状态（阈值取 1990–1999 年的三分位）和 GARCH(1,1) 创新（全样本不带标签拟合，以及只用预样本拟合两种），计算方向向量，按 26 周分块、4 周缓冲拆分 |
| `make_jobs_v3.py` | 生成主分析任务，以及 ind30 的安慰剂检验（状态序列循环平移 200 次）和 bootstrap 原假设（200 个数据集）任务 |
| `run_v3.R` | 调用 `sim/R` 中冻结的学习器和统计量（不做任何改动），计算 MCA-kDET 及其变体、DISCO、MMD、MST、Schott 的 p 值；主分析任务还保存每个状态、每个学习器的 T 和 AUC |
| `report_v3.py` | 汇总主结果和 Holm 校正、校准检查的拒绝率（附 Clopper–Pearson 区间）、定位表，以及按状态计算的经济描述量 |

## 口径

- 观测是一周，向量的坐标是各行业，总体是三种状态（不同的周组成）。主分析为 d = 30。
- 主检验：ind30 的 `innov` 和 `dir` 两项，方法为 MCA-kDET，两项之间做 Holm 校正。`raw` 只作基准。
- 数据有时间依赖，p 值是近似的；它们的可靠性由安慰剂检验和 bootstrap 原假设两项校准检查来说明，结果无论好坏都报告。
- 没有改动冻结的代码，也没有改动论文草稿。

## 修订 1（2026-10-28）：依赖稳健的推断

原安慰剂检查没有通过：状态序列循环平移后，MCA 按周置换的拒绝率为 27.5%–29.0%；而在逐周独立的 bootstrap 原假设下是 4.5%–6.5%。原因是行业间的依赖结构随年代缓慢变化，按周置换把不同时期的周当成可交换的，灵活的学习器能分辨不同时期。原结果完整保留在报告中。

修订内容见 `protocol_amendment1.json`。修订是在看过原安慰剂结果和按周置换 p 值之后决定的，但在算任何修订统计量之前就写定了。

- **主推断：旋转检验。** 把真实 VIX 状态序列循环平移 52 到 T−52 周的每一种平移，都重跑整个流程；真实状态下的 T_max 在这些平移中的排位就是 p 值。平移保留了数据本身的全部时间依赖和状态的持续性，只切断状态与数据之间的对应关系。对应的原假设是"VIX 状态与创新过程独立"，在这个原假设下检验有效，不需要假设各周可交换。innov 和 dir 两项做 Holm 校正。
- **次要推断：时期内置换。** 只在同一个 L 周的日历窗口内置换测试周的标签，L 取 26、52、104。先在原来的 200 个安慰剂序列上检查校准，再算真实 p 值，全部报告。
- **运行**：`run_v3_all.bat` 跑完后，双击 `run_v3b.bat`（约 4000 个任务，32 核约 30 分钟），结果见 `results\报告_v3_依赖稳健.md`。
- `run_v3.R` 只在包装层增加了时期内置换，并记录观测统计量 `stat_obs`。冻结的引擎 `sim/R/tests.R` 没有改动。
