## 已固定的设计

- 候选股为2014-12-31沪深300权重前60；仅按2010–2014价格覆盖≥98%、正成交量≥95%筛选，取权重前30。主分析用前10，维数检查用前20/30。后续是否退市不用于选股，主10股金融业集中。
- 米筐下载2009-12-28至2025-12-31后复权日收盘价、成交量、全天停牌与历史指数权重。来源参数和SHA256在 `raw/download_manifest.json`。行情属于用户授权的数据，未上传或公开发布。
- 周单位为Friday日历周，中国当周最后交易日价格的相邻周复权对数差×100。要求两个端点均有观测且未停牌；不前填，不将多周复牌收益当作一周。计划窗口2015-01-09至2025-12-26，**实际完整向量止于2025-01-31**，因为历史名单中有后续停牌/退市股票。主分析573周中212训练、211测试、29缓冲、121缺失。
- 标签为上一周美国最后交易日VIX收盘对应的低/中/高风险组。阈值只从2010–2014周VIX确定，为14.8766667和18.43；在中国本周一开盘前已知。Cboe提供公开VIX，未使用本周待检验的A股收益定义状态。
- 均值及GARCH(1,1) Gaussian QML参数仅用2015年前数据；以后逐步用过去收益推进方差。缺失周用模型条件二阶矩推进。分类器及坐标尺度仅由其拟合周估计。
- 主拆分26周整块、一半拟合、一半测试；测试与拟合块相隔至少4个日历周。拆分可依状态和缺失结构满足每组拟合/测试至少30周，不依检验结果选择。四种方法用相同数据、尺度及4999组置换标签。
- `study_plan.json` 在计算检验前固定18项：主分析、20/30股、13/52周块、8周缓冲、未过滤、随机拆分、VIX15/25阈值、4个每四周抽稀偏移、5个额外拆分。全部报告，不用最小p选方法或设定。

## 校准口径

过滤与缓冲不能证明残差独立，周标签置换是**近似校准**，原文iid有限样本定理不自动适用。主分析4999是标签置换次数，不是独立实证重复。各配置反复使用相同日期，次数占比也不是功效。单个数据集的p值大小不是通用的功效比较。

VIX是美国隐含风险，不能称为A股自身市场状态；行业集中、非随机缺失、不同状态的日期结构、长样本参数失配及剩余依赖均需报告。加股票也改变完整周交集，不能将维数检查的变化唯一归因于维数。

5. `report_study.py --preview-dir=<临时PNG目录>`：独立复核、汇总CSV、4幅矢量图和中文报告。
6. `build_workbook.mjs`：将已核验表格制作成 `results/股票实证结果.xlsx`。
